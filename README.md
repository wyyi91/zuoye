# PID温度控制仿真系统 v1.0

基于双惯性环节模型的温度控制仿真教学软件。

## 功能特点

- **5种控制策略**：普通PID、单回路PID（抗饱和）、前馈+反馈、串级PID、串级+前馈
- **实时波形显示**：SV/PV/u/干扰/误差 五条曲线同步显示
- **手动/自动模式**：支持无扰动切换
- **方波干扰模拟**：可配置振幅和持续时间
- **用户权限管理**：管理员/普通用户双角色
- **历史数据查询**：支持回放和Excel导出
- **完善的异常处理**：任何情况不闪退

## 快速开始

### 环境要求
- Python 3.10+
- Windows 10/11

### 安装依赖
```bash
pip install -r requirements.txt
```

### 运行程序
```bash
python src/main.py
```

### 默认账号
| 用户名 | 密码 | 角色 |
|--------|------|------|
| admin | admin123 | 管理员 |
| user | user123 | 普通用户 |

## 目录结构

```
SimControl/
├── src/                 # 源代码
│   ├── control/         # 控制算法（PID/串级/前馈）
│   ├── model/           # 被控对象模型
│   ├── ui/              # 用户界面
│   ├── user/            # 用户管理
│   └── utils/           # 工具类
├── data/                # 运行时数据（自动生成）
├── tests/               # 测试代码
├── assets/              # 静态资源
└── dist/                # 打包输出
```
